# OK2Merge 1.0 Readiness Gate (free-first)

Beta surfaces: PWA link (iPhone via Safari install, Android via Chrome) + signed
sideload APK attached to GitHub Releases. No store tracks until revenue.

## Gate
- [ ] Fresh install → GitHub sign-in works (PWA + APK)
- [ ] PR needing review appears in inbox with AI summary
- [ ] Swipe right → human confirm (WebAuthn/biometric) → approve posts to GitHub
- [ ] Swipe left → request changes with comment posts to GitHub
- [ ] Push arrives on review-requested (needs Firebase wired — see below)
- [ ] Widget shows count after sync, tap deep-links to inbox (APK only)
- [ ] Settings → delete account wipes everything; reinstall shows logged-out

## Results
- PWA: _pending (needs a host URL for the OAuth callback + install link)_
- APK: signed release builds locally (`assembleRelease`, beta key); _pending install test on a real Android device_

## Win criteria (public beta, 10 teams, free)
- Median time-to-first-review drops vs. baseline
- >30% of reviews happen on phone
- Kill rule: <30% on-phone after 2 weeks → pivot to read-only triage
