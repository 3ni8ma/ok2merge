# OK2Merge 1.0 Readiness Gate

Run on a clean iPhone AND a clean Android before any public track.
Builds: TestFlight internal + Play internal. PWA preview: `npm run build` in `app/`.

## Gate
- [ ] Fresh install → Apple sign-in works
- [ ] Connect GitHub (repo scope) works
- [ ] PR needing review appears in inbox with AI summary
- [ ] Swipe right → biometric → approve posts to GitHub
- [ ] Swipe left → request changes with comment posts to GitHub
- [ ] Push arrives on review-requested
- [ ] Widget shows count after sync, tap deep-links to inbox
- [ ] Settings → delete account wipes everything; reinstall shows logged-out
