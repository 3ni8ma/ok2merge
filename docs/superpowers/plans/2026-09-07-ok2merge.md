# OK2Merge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship OK2Merge 1.0 — a native iOS + Android app that clears GitHub PR reviews from a phone (swipe to approve, biometric to merge), with AI summaries, push, a glanceable widget, and IAP — through TestFlight/Play testing to both stores.

**Architecture:** Capacitor (React + Vite + Tailwind) web app in iOS/Android native shells talks only to our FastAPI backend; the backend proxies GitHub (tokens in Supabase Vault, never on device) and calls the AI summarizer server-side. Supabase owns auth (Apple + GitHub link), Postgres, and push-token storage. One plan, built in dependency order: backend API first (independently testable), then app, then widget, then store ship. Widget and app are not split into separate plans because neither is shippable alone; backend tasks are independently verifiable via their API tests.

**Tech Stack:** Capacitor 8 + React + Vite + Tailwind (TypeScript, react-router), Supabase (Auth + Postgres + Vault), FastAPI + httpx + respx/pytest, google-genai (summaries, env-pinned model), firebase-admin (FCM push to both platforms), @revenuecat/purchases-capacitor (IAP), @aparajita/capacitor-biometric-auth, @capawesome/capacitor-apple-sign-in, WidgetKit (Swift) + Android RemoteViews widget (Kotlin), Xcode + Gradle builds.

**Spec:** `docs/superpowers/specs/2026-09-07-pr-swipe-design.md` (+ `docs/brand-guidelines.md` for voice, palette, store copy)

## Global Constraints

- GitHub-only v1; GitHub OAuth scope is exactly `repo`; OAuth App (not GitHub App) for v1.
- Phone never holds a GitHub token or AI key; all GitHub + AI traffic is server-side.
- AI summaries: diff truncated to ~12k chars; cache keyed by commit SHA, 30-day TTL, per-user; beta cap ~50 summaries/user/day; summary slot degrades to Retry, never blocks review.
- Review events allowlist: `APPROVE`, `REQUEST_CHANGES`, `COMMENT` only; every review POST carries a client-generated idempotency key.
- Every approval requires biometric confirm (FaceID / Android Biometric; device PIN fallback); swipes disabled offline.
- Auth is two-step: Sign in with Apple first, then Connect GitHub; in-app account deletion must fully wipe.
- Money only via IAP (StoreKit + Play Billing through RevenueCat); no Stripe anywhere in-app.
- No token, diff, or AI key in logs, ever.
- Brand: Merge `#22C55E`, Ink `#0D1117`, Paper `#F6F8FA`, Amber `#F59E0B`, Red `#EF4444`; Space Grotesk display, Inter UI.
- Widget v1 is read-only (no actions); shows "updated Xm ago" + stale state.

Create `api/app/store.py`:
```python
from supabase import create_client
from .config import SUPABASE_URL, SUPABASE_SERVICE_KEY

sb = create_client(SUPABASE_URL, SUPABASE_SERVICE_KEY)

def store_github_token(user_id: str, token: str, login: str) -> None:
    secret_id = sb.rpc("vault_create_secret", {"p_secret": token}).execute().data
    sb.table("github_tokens").upsert(
        {"user_id": user_id, "secret_id": secret_id, "github_login": login}
    ).execute()

def read_github_token(user_id: str):
    row = sb.table("github_tokens").select("secret_id,github_login").eq("user_id", user_id).single().execute().data
    if not row:
        return None
    secret = sb.rpc("vault_read_secret", {"p_secret_id": row["secret_id"]}).execute().data
    return secret, row["github_login"]
```
SQL helpers (append to `supabase/schema.sql` in this step):
```sql
create or replace function vault_create_secret(p_secret text) returns uuid
language plpgsql security definer as $$
declare sid uuid; begin
  insert into vault.secrets (secret) values (p_secret) returning id into sid;
  return sid; end $$;

create or replace function vault_read_secret(p_secret_id uuid) returns text
language plpgsql security definer as $$
declare s text; begin
  select decrypted_secret into s from vault.decrypted_secrets where id = p_secret_id;
  return s; end $$;
```
Create `api/app/routes/github_connect.py`:
```python
import httpx
from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel
from ..deps import get_current_user
from ..store import store_github_token, sb

router = APIRouter()

class ConnectBody(BaseModel):
    token: str
    login: str

@router.post("/api/github/connect")
def connect(body: ConnectBody, user_id: str = Depends(get_current_user)):
    me = httpx.get("https://api.github.com/user",
                   headers={"Authorization": f"Bearer {body.token}"},
                   timeout=15)
    if me.status_code != 200:
        raise HTTPException(502, "github token rejected by github")
    store_github_token(user_id, body.token, body.login)
    sb.table("profiles").upsert({"user_id": user_id}).execute()
    sb.table("entitlements").upsert({"user_id": user_id}).execute()
    return {"ok": True, "login": body.login}

@router.delete("/api/github/connect")
def disconnect(user_id: str = Depends(get_current_user)):
    sb.table("github_tokens").delete().eq("user_id", user_id).execute()
    return {"ok": True}
```

```python
import time
import httpx

_cache: dict = {}
CACHE_TTL = 60

def gh(token: str) -> httpx.Client:
    return httpx.Client(base_url="https://api.github.com",
                        headers={"Authorization": f"Bearer {token}",
                                 "Accept": "application/vnd.github+json",
                                 "X-GitHub-Api-Version": "2022-11-28"},
                        timeout=20)

def search_review_requested(token: str, login: str) -> list:
    key = ("inbox", login)
    if key in _cache and time.time() - _cache[key][0] < CACHE_TTL:
        return _cache[key][1]
    with gh(token) as c:
        items = c.get("/search/issues",
                      params={"q": "is:pr is:open review-requested:@me",
                              "per_page": 30}).json()["items"]
        out = []
        for it in items:
            owner_repo = it["repository_url"].split("repos/")[1]
            num = it["number"]
            pr = c.get(f"/repos/{owner_repo}/pulls/{num}").json()
            out.append({"repo": owner_repo, "number": num,
                        "title": it["title"], "author": it["user"]["login"],
                        "head_sha": pr["head"]["sha"]})
        _cache[key] = (time.time(), out)
        return out
```

```python
import httpx
from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel, field_validator
from typing import Literal
from ..deps import get_current_user
from ..store import read_github_token, sb

router = APIRouter()

class ReviewBody(BaseModel):
    repo: str
    number: int
    event: Literal["APPROVE", "REQUEST_CHANGES", "COMMENT"]
    body: str = ""
    key: str

    @field_validator("event", mode="before")
    @classmethod
    def upper(cls, v: str) -> str:
        return str(v).upper()

@router.post("/api/reviews")
def post_review(b: ReviewBody, user_id: str = Depends(get_current_user)):
    seen = sb.table("idempotency_keys").select("status,body").eq("user_id", user_id)\
        .eq("key", b.key).execute().data
    if seen:
        return seen[0]["body"]
    found = read_github_token(user_id)
    if not found:
        raise HTTPException(409, "github not connected")
    token, _ = found
    r = httpx.post(f"https://api.github.com/repos/{b.repo}/pulls/{b.number}/reviews",
                   headers={"Authorization": f"Bearer {token}",
                            "Accept": "application/vnd.github+json"},
                   json={"event": b.event, "body": b.body}, timeout=20)
    if r.status_code not in (200, 201):
        raise HTTPException(502, f"github rejected review: {r.status_code}")
    out = {"ok": True, "id": r.json().get("id")}
    sb.table("idempotency_keys").insert(
        {"user_id": user_id, "key": b.key, "status": r.status_code, "body": out}).execute()
    return out
```

```python
import hmac, os
from fastapi import APIRouter, Header, HTTPException, Request
from firebase_admin import credentials, initialize_app, messaging
from ..store import sb

router = APIRouter()
GH_SECRET = os.environ.get("GITHUB_WEBHOOK_SECRET", "")
RC_SECRET = os.environ.get("REVENUECAT_WEBHOOK_SECRET", "")

_fcm = None
def fcm():
    global _fcm
    if _fcm is None:
        initialize_app(credentials.Certificate(os.environ["FIREBASE_SERVICE_ACCOUNT_JSON"]))
        _fcm = True
    return messaging

@router.post("/webhooks/github")
async def github_hook(request: Request,
                      event: str = Header("", alias="X-GitHub-Event"),
                      sig: str = Header("", alias="X-Hub-Signature-256")):
    raw = await request.body()
    want = "sha256=" + hmac.new(GH_SECRET.encode(), raw, "sha256").hexdigest()
    if not hmac.compare_digest(want, sig):
        raise HTTPException(401, "bad signature")
    if event not in ("pull_request", "pull_request_review", "check_run", "issue_comment"):
        return {"ok": True, "ignored": True}
    payload = await request.json()
    login = ((payload.get("requested_reviewer") or {}).get("login")
             or (payload.get("comment") or {}).get("user", {}).get("login"))
    if not login:
        return {"ok": True, "ignored": True}
    prof = sb.table("github_tokens").select("user_id").eq("github_login", login).execute().data
    if not prof:
        return {"ok": True, "ignored": True}
    toks = sb.table("push_tokens").select("fcm_token").eq("user_id", prof[0]["user_id"]).execute().data
    sent = 0
    for t in toks:  # FCM fans out to Android directly and to iOS via APNs
        fcm().send(messaging.Message(
            token=t["fcm_token"],
            notification=messaging.Notification(title="OK2Merge", body="A PR needs your review"),
            data={"route": "/"}))
        sent += 1
    return {"ok": True, "pushed": sent}

@router.post("/webhooks/revenuecat")
async def rc_hook(request: Request, authorization: str = Header("")):
    if authorization != f"Bearer {RC_SECRET}":
        raise HTTPException(401, "bad secret")
    evt = (await request.json()).get("event", {})

        "INITIAL_PURCHASE", "RENEWAL") else "free"
```

```ts
import { registerPlugin } from "@capacitor/core";
export interface Snapshot { count: number; oldestAgeMin: number; ciFails: number; updatedAt: number }
interface Bridge { writeSnapshot(o: { json: string }): Promise<void> }
const native = registerPlugin<Bridge>("WidgetBridge");
export function shapeSnapshot(s: Partial<Snapshot>): Snapshot {
  return { count: 0, oldestAgeMin: 0, ciFails: 0, updatedAt: Date.now(), ...s };
}
export const writeSnapshot = (s: Partial<Snapshot>) =>
  native.writeSnapshot({ json: JSON.stringify(shapeSnapshot(s)) });
```

```swift
    call.resolve()

}
```

Create `targets/widget-ios/OK2MergeWidget.swift`:
```swift
import WidgetKit
import SwiftUI

struct Snapshot: Decodable { var count = 0; var oldestAgeMin = 0; var ciFails = 0; var updatedAt = 0 }
struct Entry: TimelineEntry { let date = Date(); let snap: Snapshot }

struct Provider: TimelineProvider {
  func placeholder(in c: Context) -> Entry { Entry(snap: Snapshot()) }
  func getSnapshot(in c: Context, completion: @escaping (Entry) -> ()) {
    completion(Entry(snap: load())); }
  func getTimeline(in c: Context, completion: @escaping (Timeline<Entry>) -> ()) {
    completion(Timeline(entries: [Entry(snap: load())], policy: .after(Date().addingTimeInterval(15*60)))); }
  func load() -> Snapshot {
    guard let s = UserDefaults(suiteName: "group.app.ok2merge.dev")?.string(forKey: "snapshot"),
          let d = s.data(using: .utf8),
          let snap = try? JSONDecoder().decode(Snapshot.self, from: d) else { return Snapshot() }
    return snap
  }
}

struct WidgetView: View {
  var e: Entry
  var body: some View {
    VStack(alignment: .leading) {
      Text("\(e.snap.count) to review").font(.headline).foregroundColor(.white)
      Text("oldest \(e.snap.oldestAgeMin)m · CI fails \(e.snap.ciFails)").font(.caption).foregroundColor(.gray)
      Spacer()
      Text("updated \(Int(Date().timeIntervalSince1970).advanced(by: -e.snap.updatedAt/1000))s ago")
        .font(.caption2).foregroundColor(.gray)
    }.padding().background(Color(red: 0.05, green: 0.07, blue: 0.09))
    .widgetURL(URL(string: "ok2merge://"))  // root route IS the inbox (app/app/index.tsx)
  }
}

@main struct OK2MergeWidget: Widget {
  var body: some WidgetConfiguration {
    StaticConfiguration(kind: "ok2merge", provider: Provider()) { e in WidgetView(e: e) }
      .configurationDisplayName("OK2Merge").description("PRs waiting on you.")
      .supportedFamilies([.systemSmall, .systemMedium])
  }
}
```

```kotlin
package app.ok2merge.dev.widget
import android.app.PendingIntent
import android.appwidget.*
import android.content.*
import android.net.Uri
import android.widget.RemoteViews
import org.json.JSONObject

class OK2MergeWidget : AppWidgetProvider() {
  override fun onUpdate(c: Context, mgr: AppWidgetManager, ids: IntArray) {
    val raw = c.getSharedPreferences("ok2merge_widget", 0).getString("snapshot", "{}")
    val j = JSONObject(raw ?: "{}")
    val mins = ((System.currentTimeMillis() - j.optLong("updatedAt")) / 60000).toInt()
    val v = RemoteViews(c.packageName, R.layout.widget_layout).apply {
      setTextViewText(R.id.count, "${j.optInt("count")} to review")
      setTextViewText(R.id.sub, "oldest ${j.optInt("oldestAgeMin")}m · updated ${mins}m ago")
      setOnClickPendingIntent(R.id.root, PendingIntent.getActivity(c, 0,
        Intent(Intent.ACTION_VIEW, Uri.parse("ok2merge://")),  // root route IS the inbox
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE))
    }
    ids.forEach { mgr.updateAppWidget(it, v) }
  }
}
```
